# @denotui/create

Starter template for **denotui**:

```sh
deno create jsr:@denotui/create my-app
cd my-app
deno task start
```

Generates `deno.json` (app barrel + compiler, `denotui:build`/`start` tasks),
`main.ts`, `App.tui` and `.gitignore`. The template already has everything it
needs; no installer pass is required.

Docs: [`docs/guide/first-app.md`](../../docs/guide/first-app.md).
